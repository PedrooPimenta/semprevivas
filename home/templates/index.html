O que é Sempre Vivas?

Sempre Vivas é um projeto de desenvolvimento de software dedicado à construção de um sistema especializado no gerenciamento de espécies da família Eriocaulaceae, popularmente conhecidas como "sempre-vivas". Nossa plataforma facilita o registro, organização e consulta de dados botânicos, oferecendo uma solução completa para pesquisadores, coletores e entusiastas da flora.
